# Taste
- 使用中文交流，期望以中文得到回复与解释。Confidence: 0.7
- 设计或实现功能前，期望先对照权威来源与参考实现（协议规范及其源码、zed、waku 的对应实现），而不是凭假设推断；尤其涉及 UI 形态时应引用参考实现的具体做法与出处，并诚实说明哪些没查、哪些没验证。Confidence: 0.8
- 会以结构化形式（严重级别如 P1/P2 + 文件:行号 + 根因描述）提交问题清单，并要求先「核实」再修复：逐条对照源码确认是否属实、说明实际根因（若比报告更严重就点明），修完还要给出验证结果与仍然存在的边界/未验证项，而不是只报完成。Confidence: 0.65
- 面向中文用户的 UI 文案用中文，代码、注释与标识符保持英文（界面语言与代码语言刻意分离）。Confidence: 0.6
- 改动后以可执行的验证收尾为准：`cargo fmt`/`check`/`clippy`/`test` 全绿，并做一次启动烟测确认不 panic，不留残留进程。Confidence: 0.6
- UI 走精简路线：菜单/列表项倾向于纯文字、文案从简，不要加装饰性图标（明确要求「删除会话不要加 icon」、「删除会话 改为 删除」）。Confidence: 0.5
- 选择器/列表项只显示名称等必要信息即可，不要在行里展示来源提供的冗长说明（明确要求 mode 只显示 `build`/`plan`，不要 agent 的描述文本）；宁可把这类数据从来源处直接去掉，也不在渲染时丢弃。Confidence: 0.5
- 代码评审期望覆盖全部 diff，并从「代码架构、代码复用、组件化、代码质量」等多个维度给出分析，而非只挑功能缺陷。Confidence: 0.5
- 提出「分析某个模块的实现架构」时，期望得到分层的深度解读：模块边界与解耦方式、线程/并发与所有权模型、通道与数据流、状态归属、关键设计决策及其权衡与已知约束，并附具体「文件:行号」引用，而不是泛泛的概念概述。Confidence: 0.5
- UI 布局偏好：需要用户即时决策/操作的控件（如权限审批卡）放在输入区（composer）上方、始终可见，而不是内联在会滚动的对话流中；宁可牺牲「挂在那次具体调用上」的关联性，也要保证决策入口不移位。Confidence: 0.5
- 反对把「调用方必须记得手动做」的不变式留在各个调用点：倾向抽共享挂载点（如 `src/ui/layers.rs::window_layers`）让所有窗口统一走它，理由是这类失败模式静默无害化（弹窗没渲染和压根没弹看起来一模一样），并接受为此多抽一层抽象。Confidence: 0.6
- 判断某个 workaround 能否删除时，要求跨版本比对上游源码（如 gpui-component 0.6.0 vs 0.6.1 的 `Root::render`）确认行为是否已变，而不是假设「等升级就能删」。Confidence: 0.6
- 解释框架/库坑的知识应集中放进共享 helper 的 doc comment，调用点只留一行；注释必须解释「为什么」，否则读者会误判其用途（如把 `.relative()` 当成 dialog 定位所需）。Confidence: 0.6
- 反对 API 倒置与冗余参数：调用方能从现有上下文派生的东西（如 `cx.weak_entity()` 之于传入的 `WeakEntity`）不应作为参数要求调用方再传一次，签名也要与同类既有方法（如 `delete_session(…, cx: &mut Context<Self>)`）保持一致。Confidence: 0.55
- 明确反对把一次性要求上升为通则：指出把「删除会话不要 icon」概括成「菜单/列表项一律不要装饰性图标」会在带图标的工具栏等场景误导，宁可保留为窄范围、低置信度的记录。Confidence: 0.6
- 单文件明显过大（如 1000+ 行）时要求做模块化拆分：拆成同级模块目录（`src/x.rs` → `src/x/mod.rs` 门面 + 若干职责单一的子文件），而不是继续在单文件里堆叠。Confidence: 0.6
- 结构性重构要求是「纯搬迁」：公共 API、运行行为、并发/通道模型不变，外部调用点零改动，且不在同一 diff 里夹带顺带的内部整理（不抽内联闭包、不合并重复逻辑）；判定标准用「外部文件零改动」这类可核对的条件，而不是凭估算。Confidence: 0.55
- 拆分模块时测试跟随被测模块分布（纯函数测试进对应子模块、只在同模块可访问的私有字段测试留在该子模块、共享测试工具单独成文件），而不是全部堆在 mod.rs 底部。Confidence: 0.45
- 遇到需要决策的边界（拆分力度、测试归属）宁可先问清再动手，而不是按自己的判断直接改完。Confidence: 0.45
- UI 尺寸避免「凭空的固定值」：容器/行应按内容自适应（可配 min/max 夹取）而不是写死宽高，尤其不要为不存在的内容预留空间；发现 `w(px(280.))` 之类无依据的硬编码即视为浪费并倾向删除。Confidence: 0.5
